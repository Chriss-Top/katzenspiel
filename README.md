# 🐾 Mein Kätzchen

Ein Browserspiel für Kinder von 6 bis 8 Jahren: Du pflegst eine kleine Babykatze, bis sie eine große Katze ist.

## Spielen

`index.html` im Browser öffnen. Es braucht keine Installation und keinen Server.

## Steuerung

| Taste | Was passiert |
|---|---|
| Pfeiltasten (oder WASD) | Der Junge läuft herum |
| Leertaste / Enter | Sache aufheben, der Katze geben, streicheln |

Auf Tablets und Handys erscheinen Pfeil-Knöpfe und ein **OK**-Knopf.

## So geht's

Über der Katze erscheint eine **Denkblase**. Das Kind muss selbst herausfinden, was die Katze braucht, und die passende Sache holen:

| Denkblase | Was zu tun ist |
|---|---|
| 🐟 Fisch | Futter bringen |
| 💧 Tropfen | Wasser bringen |
| ❤️ Herz | Mit leeren Händen streicheln |
| 🌙 Mond | Decke bringen (Nickerchen) |
| 🧶 Wollknäuel | Spielen: Wollknäuel oder Laser bringen, dann startet ein Minispiel |
| 🪮 Bürste | Bürsten (das Fell ist zerzaust) |
| 🚽 Katzenklo | Mit der Schaufel das Katzenklo sauber machen |

Wartet die Katze lange, leuchtet die passende Sache golden auf.

### Level

1. Babykatze (6 Wochen): Futter, Wasser, Streicheln, Schlafen
2. Kleines Kätzchen (3 Monate): dazu **Spielen** (Minispiel „Wollknäuel fangen“)
3. Junge Katze (6 Monate): dazu **Bürsten**
4. Fast erwachsen (1 Jahr): dazu **Katzenklo** und **Laser** (Minispiel „Laser-Jagd“)
5. Große Katze (2 Jahre): alles, mit mehr Pflege

Am Ende gibt es eine Urkunde, danach geht es im freien Spiel weiter. Der Spielstand wird im Browser gespeichert.

Man kann nicht verlieren. Ein falscher Gegenstand führt nur zu einem freundlichen Hinweis. Die Texte werden vorgelesen; das lässt sich mit 🔊 abschalten.
